Neon Login Page

A modern, sleek, and responsive login page featuring glowing neon effects and smooth interactive transitions built with pure HTML, CSS, and JavaScript.

🌟 Features

- Neon Glow Aesthetic: Dark-themed UI enhanced with luminous neon accents and smooth box shadows.
- Interactive UI: Dynamic input focus states, hover animations, and basic client-side form interactions.
- Clean Structure: Built with modular HTML5, modern CSS3 styling, and vanilla JavaScript.
- Responsive Layout: Adapts seamlessly across desktop monitors, tablets, and mobile screens.

 📁 Project Structure

```text
Neon-Login-page/
├── CSS/
│   └── style.css        # Neon styles, animations, and responsive layout
├── JS/
│   └── script.js       # Form validation and dynamic UI triggers
└── login.html          # Main HTML structure for the login interface
```

🛠️ Built With
HTML5 – Semantic markup and form elements
CSS3 – Custom properties, neon box-shadows, keyframe animations, and flexbox
Vanilla JavaScript – DOM manipulation and interactive logic
